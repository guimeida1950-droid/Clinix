# Clinix

Sistema desktop de gestão para clínicas desenvolvido em Java.

## 🚀 Funcionalidades

- Cadastro de pacientes
- Edição e exclusão de pacientes
- Pesquisa de pacientes
- Agendamento de consultas
- Edição e exclusão de consultas
- Prontuários médicos
- Visualização detalhada de prontuários
- Configurações do sistema
- Conexão com MySQL
- Suporte a banco de dados em rede
- Aplicação Windows

## 🛠️ Tecnologias

- Java
- Java Swing
- MySQL
- JDBC
- Git
- GitHub
- jpackage
- WiX Toolset

## 🗄️ Banco de dados

O sistema utiliza MySQL para armazenar:

- Pacientes
- Consultas
- Prontuários

## ▶️ Como executar

1. Instale o Java.
2. Configure o MySQL.
3. Crie o banco `clinix`.
4. Configure as credenciais no sistema.
5. Execute o projeto.

## 📌 Objetivo

Projeto desenvolvido para estudos e composição de portfólio,
com foco em desenvolvimento Java desktop, banco de dados e
arquitetura de aplicações.
